## Doc Weapon Recommendations

"just go gog, craftables suck lmao" — best-in-slot for every element is the
Gogma Artian. Doc prose spells it "Headman's Hamus"; the in-game builder
images spell it "Headsman's Hamus" (module uses the builder spelling).

| Element | Best | Craftable |
| --- | --- | --- |
| Fire | Headsman's Hamus | Wyvern Blade "Lily" |
| Water | Headsman's Hamus | Tamonowo |
| Thunder | Headsman's Hamus | Heaven's Thunder |
| Ice | Headsman's Hamus | None |
| Dragon | Headsman's Hamus | Blazing Rafel |
| Paralysis | Headsman's Hamus | Lala Ornithocton |
| Blast | Headsman's Hamus | None |

### Doc Artian Roll — Raw (Fig 3.2A)

- Production Bonus: Element Infusion +30, Attack Infusion +5 x3;
  Element Type: Paralysis (shown — doc text says match element per monster,
  one Long Sword per element); Attack Focus.
- Active Skills: Gore Magala's Tyranny + Lord's Soul.
- Reinforcement Bonus: Attack Boost EX +12 x2, Attack Boost III +9 x2,
  Sharpness/Ammo Boost EX +50.
- Doc text: 1 affinity reinforcement is fine (small damage loss), but never
  more than 1. "Gore + Lord's Soul is no longer needed — just roll for
  Gore" (the group skill no longer matters).

### Doc Artian Roll — Full Element (Fig 3.2C)

- Production Bonus: Element Infusion +30, Attack Infusion +5 x3; Water
  shown; **Element Focus**.
- Active Skills: Gore Magala's Tyranny + Guardian's Pulse.
- Reinforcement Bonus: Element Boost EX +90 x2, Element Boost II +60 x2,
  Sharpness/Ammo Boost EX +50.
- Full element is only used for Odogaron, Gravios, and Gogmazios. Anti-Gog
  requires rolling the Gog set bonus (Gogmapocalypse), not Gore. Group
  skill does not matter.

## Endgame Builds (§3.3 "Raw but it's actually Element flavored")

Because element comes at no cost on Artian/Gog weapons, raw sets with
matched element are optimal.

## Doc Build 3.3.1: Gore/Guts

Only requires rolling for Gore. A raw/status LS can be used instead, but
element is stronger on all matchups. For AT Arkveld: go Dragon element and
slot Dragon Resistance 3. Blango Waist can swap to Lagi β and WEX Charm to
Agi for an extra lvl 1 slot, at the cost of the dragon resistance.

### 3.3.1 Weapon

Headsman's Hamus — Dragon Attack Infusion x3, Attack Focus; Set: Gore
Magala's Tyranny, No Group Skill; Reinforce: Attack Boost EX x2, Attack

## Endgame Builds (§3.4 FULL ELEMENT)

Used only for Odogaron, Gravios, and Gogmazios matchups. Not represented in
the data module (module scopes to the general + anti-monster raw sets).

## Doc Build 3.4.1: Anti-Odogaron

Odo is super weak to water; Element Attack / Critical Element investment
outdamages raw. Wex over Agi (Odo is a Guardian); Dragon Res 3 prevents
Dragonblight.

- Weapon: Headsman's Hamus — Water Attack Infusion x3, Element Focus; Gore
  Magala's Tyranny, No Group; Element Boost EX x2, Element Boost II x2,
  Sharpness/Ammo Boost EX. Decos: Stream/Handicraft Jwl [3],
  Crit Elem/Handicraft Jwl [3], Rzr Sharp/Handicraft Jwl [3].
- Armor: Udra Mirehelm γ (Sane [1] x3), Udra Miremail γ (Tenderizer [3],
  Chain [3]), Sororal Vambraces α (Counter [2]), Lagiacrus Coil β
  (Mighty [2] x2, Dragon Res [1]), Duna Wildgreaves γ (Flayer [3],
  Dragon Res [1] x2). Talisman: Weakness Exploit Lv. 3.
- Skills: Burst 5, Weakness Exploit 5, Antivirus 3, Counterstrike 3,
  Critical Element 3, Dragon Resistance 3, Handicraft 3, Maximum Might 3,
  Quick Sheathe 3, Razor Sharp 3, Water Attack 3, Flayer 1, Evade
  Extender 1, Partbreaker 1, one further Lv. 1 skill ILLEGIBLE (name
  blurred in image). Group/Set: Lord's Soul, Gore Magala's Tyranny I,
  Nu Udra's Mutiny I.
- Elemental Resistances: NOT IN DOC.

## Doc Build 5.1: Crit Draw (Meme Build)

Uses Critical Draw 3 to reach 100% affinity on draw attacks and stacks raw.
ISS hits harder than normal sets, but damage is lost on topples/long
openings due to reliance on Iai Slash for crit.

- Weapon: Headsman's Hamus — Dragon Attack Infusion x3, Attack Focus; Set:
  **Ebony Odogaron's Power**, No Group; Reinforce: Attack Boost EX x2,
  Attack Boost III, Sharpness/Ammo Boost EX x2. Decos: Critical
  Jewel III [3], Critical Jewel II [2], Draw Jewel III [3].
