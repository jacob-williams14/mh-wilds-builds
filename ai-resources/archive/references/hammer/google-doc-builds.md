## Notes for Cross-Referencing

- Doc Build 1 (Doshath Guts) shares the Powerhouse/Guts/Gogma concept
  with Game8's Dosha Gogma Guts but differs in 3 armor pieces (helm,
  chest, waist) and charm — kept as a separate build.
- Doc Build 4 (ArkFulgore) is declared by the doc to be an alternative
  armor spread of Doc Build 2 (Fulgore Guts) — merged into Fulgore
  Guts for the data module (alternate armor noted in the description).
- Doc Build 6 (Release Alternative MM) differs from Game8's Ful-Gore
  Critical only in the chest (Arkvulcan Mail β vs Numinous Shroud β)
  and the Gore Coil variant (α vs β), with matching set bonuses
  (Second Wind + Black Eclipse) and near-identical skills — merged
  into Game8's more current Ful-Gore Critical build.
- Doc Build 5 (Release Meta Set) has no Game8 counterpart (full-Gore
  Evade Window frenzy set) — kept as the doc's HR50-era entry.
- §4 matchup chart is Hunting Horn's ("you can use it until i make one
  for Hammer") — not transcribed.
- §6 Meme Builds is an empty solicitation — NOT IN DOC.
