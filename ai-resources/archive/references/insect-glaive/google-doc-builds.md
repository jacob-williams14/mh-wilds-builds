### Artian Glaive
(from `screenshots/insect_glaive/google_doc/shared/artian-instructions.png`)

- TU4 Gogmazios has significantly changed Artian Weapons. Basics from before like crafting them with 3 of the same element and Attack infusion still apply, but now they can be upgraded and rolled further.
- Element Focus is usually preferred for standard elemental picks, though Attack Focus is extremely close and is better on rare matchups (non-AT Arkveld). Insect Glaive is still generally a raw focused weapon.
- **Best Roll for IG**: 2 Attack EX, 2 Attack III, 1 Sharpness EX
- **Reinforcement Priority** (highest to lowest): 1 Sharpness > Attack > Affinity >>> Element
- **Active Skills**: The ideal general use combination is Gore Magala's Tyranny + Lord's Soul. See the details tab for sets using it and more info.

**Artian TLDR:**
- 3 Attack Infusion elemental parts
- Element Focus for Gogma
- Raw Attack + Sharpness Reinforcements

## Build 1: Fulgur Craftable

### Description
The previous Fulgur craftable set can now take advantage of the Weakness Exploit 3 charm to fit Gogmazios gloves over Fulgur gloves to open up space to fit Agi 5 and Burst 1 together. Maximum Might is overcapped, but Rey Coil is still the ideal Lord's Soul coil to use here as Latent Power is necessary to make up for the lost Affinity from not having a directly Affinity boosting bonus and Agitator is already on other pieces.

LP is shown at 50% uptime in which it is nearly equal to other craftable sets, but any more uptime will let it pull ahead further. It unfortunately can't fit Rey 2p easily for extended LP duration.

The USJ armor now provides this set access to 1 level of Adrenaline Rush compared to before. It is shown at 20% uptime.

## Build 4: Resentment Craftable

### Description
Resentment is another option as an efficient damage skill that can be fit on top of standard sets. While uptime on it can be inconsistent similar to Latent Power, only as low as 30% uptime is necessary for this set to start beating the previous version.

This set is essentially just a variant of the previous Lagia set, however it's being shown separately. With high uptime on Resentment these sets are the strongest options for craftable sets.

### Adjustments
(from resentment-adjustments.png)

**Set Adjustments:**

- **Earplugs 2:**
  - This set has an easy time fitting Earplugs 2 by simply dropping a Resentment point, however that does mean it will need more Resentment uptime to equalize sets without Resentment.

- **Latent Power 1:**
  - 1 point of Latent Power can be used over the Burst level to help with Affinity, roughly being equal to it at around 50% LP uptime.
  - Burst is primarily shown because external/inconsistent Affinity sources exist and it's a highly valuable frontloaded point.

- **USJ Armor:**
  - Here is a variant with USJ legs and AT Nu Udra gloves that drops a level of Agitator in exchange for 1 level of Latent Power and Adrenaline Rush.
  - While slightly weaker depending on uptimes, this set also has 3 more size 1 slots.
  - With 20% ADR and 50% LP uptime, the set equalizes the main version at around 80% Agitator uptime.
  - USJ gloves are also usable on the same set as the image, however have no advantage over the USJ leg variant linked outside of being able to drop 1 Resentment point for Earplugs 2.
