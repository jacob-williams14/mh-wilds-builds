## Shared Weapon Recommendations (Doc)

### Artian Weapon Template (image 29)

- **Skyscraper** (standard Artian Lance) — example shown: ATK 205, 5%
  affinity, Dragon 500
- Crafting: Broken Blade + Cracked Disc x2, all Dragon, all Attack Infusion
- Reinforcements: Element Boost x4 + Sharpness x1 (element build);
  raw/status builds swap to Attack Boost x4 + Sharpness x1
- Decos shown: Guardian/Dragon Jwl【3】, Rzr Sharp/Dragon Jwl【3】,
  Crit Elem/Dragon Jwl【3】; Blast/Raw decos: OFG 3 + Handi/Razor Sharp +
  Handi/Crit Boost
- Roll guidance: Sharpness — one mandatory, two fine. Affinity — no more
  than two, preferably 0. Element — four if element, zero if raw/status.
  Attack — four if raw/status
- Recommended stable: Fire (Attack rolls), Blast (Attack rolls), and
  Water/Thunder/Ice (Element rolls) lances; "for those who aren't insane,
  just grab a Blast Lance and call it a day"

## Build 1: FulGore (Endgame — "the current hotness")

### FulGore Description

Gore 2pc grants Frenzy; clearing it gives 15% affinity for 60s (25% with
Antivirus 3). WEX adds 30% baseline → 55%. Fulgur 2pc (Fulgur Anjanath's
Will) adds a second stamina bar so Maximum Might stays up. Total ~85% crit
from armor, 90% with a 5%-base Artian, 95% during enrage with Agitator 2.
No free slots for comfort; Coalescence can be swapped for any other skill.

## Build 2: GorJin (Endgame — speedrun/clash set)

### GorJin Description

For players learning to speedrun. Uses Resuscitate (+10 raw while suffering
an ailment — Frenzy counts before and after clearing, so it is always on).
Jin 2pc adds another 25 raw on a Power Clash for a full minute. On targets
with at least 20 elemental hitzones, FulGore pulls ahead unless fights are
approaching sub-3-minutes. MM1 beats Coalescence 2 on Arkveld and Apexes at
~40% uptime; run Coalescence 2 if MM without Fulgur stresses you.

## Notes for Cross-Referencing

- All three doc endgame sets are base-game/HR50-era (pre-TU4) → no `rank`
  field; all pieces are craftable → `tier: 'craftable'`.
- No doc set shares more than 2 armor pieces with any Game8 loadout — no
  merges under the ≤1-piece rule.
- GoreVeld is excluded from the data module: the doc itself calls it
  "always worse", and Game8's 4x Zoh Shia Comfy Tank covers the hr50
  comfort slot with verified resistances. It is kept here for the record.
- Doc set-skill naming is looser than Game8's (e.g. "Lord's Fury" appears
  in the GorJin screenshot's skill list); transcribed as shown.
