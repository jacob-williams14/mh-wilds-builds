## Doc Build 1: Hybrid Stacking (General Use / Poverty) — Meta Element Set 1

### Doc Build 1 Description

The doc's recommendation for most players: a Swiss Army Knife elemental set
requiring only ONE of Ebony Odogaron's Power or Lord's Soul on the Gogma
Artian. Slightly behind the specialized sets in all matchups but close enough
for much lower investment, and by far the comfiest of the meta options. Swap
AT Arkveld chest/legs in as desired; chest swap is mandatory for Dragon.

### Doc Build 1 Weapon

Onyx Choros (Fire shown; Attack Focus; Element Infusion +30 + 3x Attack
Infusion +5). Active set skills shown: Ebony Odogaron's Power + Fortifying
Pelt. Reinforcements: 2x Attack Boost EX +12, 2x Attack Boost III +9,
Sharpness/Ammo Boost EX +50. Secondary: Great Bagpipe.

## Doc Build 2: Raw Stacking (Lo/Mid Element) — Meta Element Set 2

### Doc Build 2 Description

Requires an Ebony Odogaron's Power + Lord's Soul weapon. In 95% of cases an
upgrade or sidegrade to Hybrid Stacking; for advanced players comfortable
dropping comfort. 0.7-4% gain vs Hybrid in raw-favored matchups (e.g. Jin
Dahaad). Uth Duna γ legs swap adds comfort at minor damage cost.

### Doc Build 2 Weapon

Onyx Choros (Water shown; Attack Focus). Active set skills: Ebony Odogaron's
Power + Lord's Soul. Same reinforcement pattern as Doc Build 1. Secondary:
Great Bagpipe.

## Doc Build 3: Ele Stacking (Hi Element) — Meta Element Set 3

### Doc Build 3 Description

Requires a Gogmapocalypse + Lord's Soul weapon. Use for the 75 HP shield from
Gogmapocalypse 4-piece or element-favored hitzones (ratio 3:1 or lower, e.g.
Rathian). Stacking the shield with Guts makes you extremely hard to kill —
"a Heroics user's equivalent of a comfort set." Expert players can leverage
Peak Performance 5 to surpass raw stacking.

### Doc Build 3 Weapon

Onyx Choros (Dragon shown; Attack Focus). Active set skills: Gogmapocalypse +
Lord's Soul. Secondary: Great Bagpipe.

## Doc Build 4: Hybrid Stacking (High Investment / Healing) — Meta Set 4

### Doc Build 4 Description

demanding, most rewarding set: zero comfort, no safety nets — both Arkveld
healing bonuses keep you topped up for Peak Performance, plus Elemental

niche.

## Notes for Cross-Referencing (Google Doc)

- Doc Build 3 (Ele Stacking) = Game8 Gogmapocalypse Guts armor 5/5 — merged.
- Doc Build 2 (Raw Stacking) shares 3/5 pieces with Game8 Gog Burst-Guts —
  kept separate (2-piece difference).
- Doc Builds 1, 2, 3, 5 require a Gogma Artian (HR100+); Doc Build 7 is the
  craftable HR100 support alternative; Doc Build 9 is the doc's HR50-100
  bridge set.
- Doc Build 6 (Status) is explicitly not recommended by the doc for late
  endgame and is not shipped as a module build.
- Matchup guidance: prioritize Fire, Water, and Dragon Artian rolls for
  coverage; Gogmazios starts Fire-weak and ends Dragon-weak; Omega Planetes
  prefers G. Resounding Galahad for survivability (Thunder for optimal
  damage).
