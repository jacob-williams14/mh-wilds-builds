## Shared Weapon Recommendations

### Artian Dual Blades (standard) — Tiltkreise

Rarity 8, ③③③ slots. Configuration varies by build:

- Elemental crit builds (Zoh Gore, Regios Gore, Focus WEX, Rey Dau):
  production 3x Affinity +5 (one lists Element +20 first), reinforcements
  4x Element +20 + Sharpness Boost +30. 350 element / 20% affinity.
- Raw builds (Regios Lord's Soul, Seregios Gore Comfy): production
  3x Attack +5, reinforcements 4x Attack +5 + Sharpness +30.
- Modified Rey Dau (raw lean): production Attack +5 + 2x Affinity +5,
  reinforcements 4x Attack +5 + Sharpness +30.
- Weapon decos (elemental): Crit Elem/Blaze Jwl [3], Focus/Blaze Jewel [3],
  Rzr Sharp/Blaze Jwl [3] (Fire example — swap element jewels to match).
- Weapon decos (raw): Critical Jewel III [3], Rzr Sharp/Handicraft Jwl [3],
  Focus/Handicraft Jewel [3].

### Gogma Artian — Eternal Cusp (HR100+ builds)

Rarity 8, 315 ATK, ③③③, 340 element, 0% affinity.

- Focus: Element Focus. Set Skill: Gogmapocalypse. Group Skill: Lord's Soul
  (Gogmapocalypse Burst build accepts any group skill).
- Production bonus: Element +20 (or +30) + 3x Attack +5, any element type.
- Reinforcement priority: 2x Element +20, 2x Attack +5, Sharpness +30.
  Aim for two Element Boost EX when amending.
- Weapon decos: Enhancer/[Element] Jwl [3], Focus/[Element] Jewel [3],
  Rzr Sharp/[Element] Jwl [3] — match your element.
