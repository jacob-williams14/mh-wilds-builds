## Notes for Cross-Referencing

**HR 100+ Builds (1–3):**
- All three use Gogma Artian weapon (Headsman's Hamus) with Lord's Soul
- Builds 1 and 3 both use Udra Miremail γ + Duna Wildgreaves γ as base
- Build 1 uses Armor Transcendence on Fulgur pieces (unique to this build)
- Build 2 (Gogma-Arkveld) is the only one using Gogmazios Mail α and Arkvulcan pieces together; 4 set skills active simultaneously
- Build 3 (Lagi-Guts Critical) swaps Latent Power for Critical Eye via Nu Udra chest, targets 100%+ affinity without LP dependency

**HR 50+ Builds (4–8):**
- All five can work with crafted charms (Appraised charm is HR100+ upgrade, not required)
- Builds 4 and 6 both use Rey Sandmail γ + Rey Sandbraces γ (Latent Power + Evade Extender base)
- Builds 4 and 5 use Gore pieces for Black Eclipse I group skill
- Builds 5, 6, 7 all run Thunderous Roar or Razor's Edge via Seregios/Rey/Lagiacrus pieces
- Build 7 (Agitator-Guts) is the most compact deco-wise — very few slots needed
- Build 8 (Evasive Comfy) is the only one using Numinous (Zoh Shia) armor; also the only one without Guts (Tenacity)

**Shared pieces across multiple builds:**
- Duna Wildgreaves γ: Builds 1, 3, 4, 5, 6 (Quick Sheathe Lv. 3 + Agitator Lv. 1)
- Lagiacrus Coil β: Builds 1, 3, 6 (WEX + Maximum Might)
- Udra Miremail γ: Builds 1, 3 (Counterstrike Lv. 2)
- Rey Sandmail γ + Rey Sandbraces γ: Builds 4, 6
