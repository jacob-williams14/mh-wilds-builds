## Shared Weapon Recommendations

### Artian Long Sword — Gogmazios (Headsman's Hamus)

**Raw Setup** (from `shared/gogma-artian-raw.png`):
- Primary weapon: **Headsman's Hamus** (Gogmazios Artian)
- Weapon Infusion: Dragon Attack Infusion x3 (or match element to monster), Attack Focus
- Active Skills: Gore Magala's Tyranny (+ Lord's Soul if possible — "no longer needed, just roll for Gore")
- Production Bonus: Attack Boost EX x2, Attack Boost III x2, Sharpness/Ammo Boost EX x1
- Notes:
  - Having 1 affinity reinforcement is fine; do NOT take more than 1 affinity reinforcement
  - Match element to the monster for each hunt

**Full Element Setup** (from `shared/gogma-artian-element.png`):
- Weapon Infusion: Element Infusion x3 + Element Focus (e.g., Water + Element Focus)
- Active Skills: Gore Magala's Tyranny + Guardian's Pulse
- Reinforcement: Element Boost EX x2, Element Boost II x2, Sharpness/Ammo Boost EX x1
- Notes:
  - Full element is only used for Odo, Goa, Grav, and Gog
  - Anti-Gog requires rolling for Gog set bonus, not Gore — Group Skill does not matter for that build

## Notes for Cross-Referencing

- All end-game builds use **Headsman's Hamus** (Gogmazios Artian) — only the Zoh Shia build uses a craftable weapon
- Builds 3.3.1 and 3.3.2 both use **Sororal Earrings α** for head; the anti-Seregios build adds Resentment synergy
- **Udra Miremail γ** appears in all four builds except Zoh Shia as the chest (Counterstrike Lv. 2)
- **Duna Wildgreaves γ** used in builds 3.3.1 and 3.3.2 (Quick Sheathe + Agitator legs)
- Build 3.3.3 (Anti-Guardian) swaps from Agitator-priority to WEX-priority because Guardian doesn't stay enraged
- Google Doc builds generally prioritize Gore Magala's Tyranny set bonus; Arkvulcan 2-piece (Arkveld's Hunger) appears in the Anti-Guardian build
- Many skill values are uncertain — cross-reference against game8 builds for the most reliable data
