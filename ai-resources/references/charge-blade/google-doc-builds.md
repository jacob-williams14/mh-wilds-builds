## Shared Weapon Recommendations (Doc)

### Gogma Artian — Promised Abyss

"just go gog, craftables suck lmao." Chrono Gear → Promised Abyss after
slaying Gogmazios; initial reinforcements can be rerolled afterwards.

- Raw (Fig.3.2A): 3x Blast (or Paralysis) Attack Infusion, Attack Focus.
  Reinforce: 2x Attack Boost EX (+12), 1x Attack Boost III (+9),
  2x Sharpness/Ammo Boost EX (+50). TL;DR: 1-2 Sharpness, rest
  Attack/Affinity, no Element.
- Element (Fig.3.2B): 3x Element Attack Infusion, Element Focus.
  Reinforce: 2x Element Boost EX (+80), 2x Element Boost II (+60),
  1x Sharpness/Ammo Boost EX. Use the same CB for Savage Axe and SAED;
  group skill does not matter.

## Notes for Cross-Referencing (Doc)

- Doc Builds 1 and 2 differ by one armor piece (head) — merge candidates
  per the ≤1-piece rule. The author recommends skipping raw entirely in
  favor of element except versus Arkveld.
- Doc Build 3 (Zoh Shia CB) is the only HR50-accessible doc set; all
  others require Gogmazios (HR100+) or AT-monster armor.
- Meme builds (§5: Raw Impact SAED, Fortify, Resuscitate) transcribed
  images exist but are explicitly non-optimal per the author — omitted.
- Matchup tables (Figs. 4.1A/4.2A) are per-monster element charts;
  headline conclusion recorded in the general-info doc, tables not
  transcribed.
- No set in the doc lists elemental resistance totals — every doc-only
  build ships with unverified placeholder resistances.
