## FAQ Highlights (from the FAQ card image)

### Is Perfect Rush good?

Yes — as long as you finish the entire combo with Perfect Rush III →
Scaling Slash → Falling Bash or Plunging Thrust. **Finishing with Spinning
Reaper or Charged Chop is never worth it.**

### Which combos should I use?

- **Lateral Slash → Return Stroke → Spinning Rising Slash → Spinning
  Reaper → (strong) Charged Chop** — highest damaging combo; default
  whenever there is a window. End at Spinning Reaper if the window is
  shorter.
- **Lateral Slash → Return Stroke → Roundslash** — for very short windows;
  loops back to Lateral Slash.
- **Shield Attack → Shield Bash → Hard Basher** — stuns (hit the head) and
  conserves sharpness; no elemental damage. Follow with Spinning Reaper or
  (strong) Charged Chop on longer openings.
- **Chop → Side Slash → Diagonal Rising Slash → Diagonal Chop** —
  repositioning combo, infinitely loopable.
- **Backstep → Charged Slash → Scaling Slash → Falling Bash / Plunging
  Thrust** — mount route with decent damage.
- **Backstep → Leaping Slash → Perfect Rush (I-III) → Scaling Slash →
  Falling Bash / Plunging Thrust** — for long topples (stun, flash, traps).

### Other FAQ answers

- Chop → Charged Chop loop: dead — "Normal Charged Chop has been massively
  nerfed. There is little reason to use this move, for now."
- Toggle focus mode: preference; SnS doesn't need to stay in focus mode.
- Backstep from neutral: enter focus mode and press Heavy Attack while
  holding back (also works after tapping Guard).
- Focus Strike: hitting a wound that is about to form (white scar) triggers
  a multi-hit move (like Sunbreak's Drill Slash); follow with Spinning
  Reaper or (strong) Charged Chop.
- Is SnS elemental? "Yes, but if you're still progressing it's best to
  stick to raw builds to limit the weapons you need to craft. Build for
  element once you reach endgame content."

## Attack Flowchart (Visby)

The doc embeds a full "Wilds SnS Attack Chart" covering Gap Closers &
Backstep, Grounded Normals, Perfect Guard (success → Counter Slash /
Charged Chop / Shield Attack / Lateral Slash / Backstep), Aerial Attacks,
Focus Strike (success requires hitting a wounded spot with Vital Stab), and
the Perfect Rush chain (Leaping Slash → PR I → PR II → PR III → Scaling
Slash; PR III is the Rise version). Knockback from blocking strong attacks
is cancelled on Perfect Guard.

## Skill Priorities (from the craftables list)

- Critical Boost 3 "should be 3 always".
- Pick either Master's Touch or Offensive Guard as the second skill (deco
  budget forces the choice).
- Max Might + Divine Blessing are "nice extra comfy/dmg" — Max Might is
  bonus crit for when you don't roll/perfect guard, a bonus rather than a
  win condition.
