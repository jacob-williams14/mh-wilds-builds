## Shared Weapon Recommendations

### Artian Weapon (HR100+ builds)

- **Limbo Llor** (Gogma Artian) — Rarity 8, ATK 698–713 (225–230),
  Element 280–320, Affinity 0%, Slots ③③③, Kinsect Level 8
- Production Bonus: Element +20/30, Attack +5 ×3
  (Element Type: Any, except Status Effects on some builds)
- Reinforcement: Attack +5 ×4 + Sharpness +30, or Attack +5 ×3 +
  Affinity +10 (EX) + Sharpness +30 (EX grade high priority)
- Focus: Attack Focus (Gogmazios Guts / Fulgur-Odo) or
  Attack/Element Focus (Max Raw)
- Set Skill / Group Skill rolls per build: Leviathan's Fury +
  Lord's Soul (Max Raw); Gore Magala's Tyranny + Lord's Soul
  (Arkveld-Gore); Gogmapocalypse + Lord's Soul (Gogmazios Guts);
  Fulgur Anjanath's Will + Lord's Soul (Fulgur-Odo)

### Artian Weapon (HR50+ builds)

- **Diprielcha** (standard Artian) — Rarity 8, ATK 682–713 (220–230),
  Element 80–280, Affinity 5–10%, Slots ③③③, Kinsect Level 8
- Production: Attack Infusion with 3 matching Element Infusions
- Reinforcement: Attack +5 ×4 + Affinity +5 (at most 1 Affinity
  bonus or infusion — affinity comes from armor skills)
- "Still the best weapon you can get as of TU2"

### Best Non-Artian Insect Glaive

- **Blazing Katir** (Zoh Shia) — Rarity 8, ATK 682 (220), Dragon 150,
  Affinity 5%, Slots ③②①, Whiteflame Torrent Lv. 1 (50 flat damage
  procs), Kinsect Level 8
- **Fractal Glaive Boltlagia** (Lagiacrus) — Rarity 8, ATK 682 (220),
  Thunder 300, Affinity 0%, Slots ③②①, Focus Lv. 2 + Convert Thunder
  Resistance Lv. 1, Kinsect Level 8 (used on Lagia-Gore Critical)
- **True Omega's Rod** (Savage Omega) — Rarity 8, ATK 651 (210),
  Fire 230, Affinity 10%, Slots ③②①, Synergy Lv. 1, Kinsect Level 9
  (used on Omega Synergy build)

### Best Mantle / Secondary Weapons (HR50+ builds)

- Corrupted Mantle — up to 10% extra Affinity and 4.5% more raw
- Secondary: Hope Cannon III (HBG) or Grimslayer Urgeom (GS)

## Notes for Cross-Referencing

- The module build `lords-soul-lagi` ("Lord's Soul Lagi", Rey γ +
  Nu Udra γ + Lagiacrus) is NOT ON PAGE as of this fetch. The page was
  last modified 2026-03-10; the build presumably existed on an earlier
  revision. Source drift — retired build.
- Omega Synergy (Build 5) is on the page but not in the module —
  source drift, new build.
- The screenshot-era HR50 transcriptions diverge heavily from the live
  page for Ful-Zoh Comfort (entirely different loadout), Rey Gore
  Agitator (chest/waist pieces), and Lagia-Gore (charm and skill
  totals). The live page (modified 2026-03-10) predates the module's
  ship date, so the live values supersede the module.
- All Game8 skill summaries assume the HR100+ appraised talisman where
  one is listed; HR50 crafted charms give slightly different totals.
