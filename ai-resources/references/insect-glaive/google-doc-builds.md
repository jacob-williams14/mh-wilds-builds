## Build 1: Lagia Craftable

**Description.** The new incarnation of a standard Lagia 2p craftable
set thanks to AT Arkveld's helm. If you haven't killed AT Arkveld
yet, use the previous version (Lagia legs + AT Rey Helm/Gloves).
Lagia 2p shown at 33% uptime; Latent Power at 50%; the USJ armor adds
1 level of Adrenaline Rush (20% uptime). AT Duna legs usable for more
spare size 1 slots. Flayer and Arkveld 2p are both extremely weak.

## Notes for Cross-Referencing

- All four sets assume elemental Gogma Artian weapons matched to the
  monster (Blast as weaker universal pick); craftable sets assume a
  clean-slate Gogmazios weapon with no bonus rolls.
- Lord's Soul in these sets comes from wearing 3 γ (AT) armor pieces,
  not from a weapon roll.
- Armor-only elemental resistances remain UNPUBLISHED for all four
  sets — the module's `unverified: true` placeholders stay.
- Module builds map: `lagia-craftable` → Build 1, `resentment` →
  Build 2, `fulgur-craftable` → Build 3, `gore-general` → Build 4.
